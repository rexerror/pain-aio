# PAIN-AiO Studio v1.7.4 (Full Portable)

Bản Portable chạy ngay không cần cài đặt (Zero-Install).

## Cách sử dụng
1. Tải bản đầy đủ (`.zip`) tại mục **[Releases](https://github.com/rexerror/pain-aio/releases/latest)** hoặc bấm **Code -> Download ZIP**.
2. Giải nén ra thư mục bất kỳ trên máy tính Windows (64-bit).
3. Chạy file **`PAIN-AiO.exe`** ở ngoài cùng.
4. Đăng nhập bằng tài khoản được Admin cấp (mỗi tài khoản khóa cố định 1 thiết bị).
